Which plan should I choose?

Choose the Web App if you vectorize pictures by hand. Choose an API plan if your own software sends the pictures.

Will it work on my images?

Try it for free on the home page: previews cost nothing.

Will the results work with my software?

The files are standard SVG, PDF, EPS and DXF, which open in common design and cutting programs.

What is the difference between the Web App and API plans?

The Web App plan is for people using the website, with unlimited pictures. API plans are for software and are counted in credits.

Do unused API credits roll over?

Yes, up to five times your monthly amount.

How do I make changes to my subscription?

This desktop version needs no account or subscription. Plans are shown for reference only.

What payment options do I have?

No payment is taken in this desktop version.

Can I integrate with the API for free?

Yes. Test mode is free and returns watermarked results.

I need a lot of API calls to make a sale, can you give me a break on pricing?

Use the free preview mode to show results to your customers, and only spend credits on the final download.

What happens when I run out of API credits?

Requests return an error until credits are added or the next month starts.

Do you offer special pricing for Academic or Non-profit users?

Get in touch through support and tell us about your project.
